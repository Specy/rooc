The microlp solver

        

            

                microlp started as a fork of minilp, a Rust linear
                programming solver archived by its author in 2020, which only solved problems
                with continuous variables.
            

            

                In the thesis I extended it with integer and binary variables using
                branch-and-bound, so it can also solve mixed-integer
                linear programs.
            

            

                It is ROOC's default solver and, since it is written entirely in Rust,
                it also runs in the browser.
            

            

                It has passed 1.5 million downloads on crates.io and is used by
                good_lp, the most popular optimization library in Rust.
            

        

    

    
    
    

        
Limitations and future work

        

            

                
Limitations

                

                    Designed for ease of use and teaching, the language lacks some features of
                    other modeling languages: for example, an arithmetic comparison cannot
                    appear inside a logical expression, as in
                    (x + y <= 5) or b.
                

                
The pipe-based architecture, however, makes it possible to add new features.

            

            

                
Future work

                

                    Indicator constraints, that is, arithmetic comparisons switched on or off
                    by a logical condition, linearized with the big M technique.
                

                

                    Documentation or an interactive course on the web platform, to teach
                    linear programming and how to use ROOC.
